# Vokit Security & Threat Modeling Skill

## Use when
Use for auth, tenancy, DB routing, recording access, file uploads, webhooks, provider credentials, KYC, payment flows, admin overrides or internet-facing infrastructure.

## Review
- trust boundaries;
- assets;
- actors;
- attack paths;
- tenant escape;
- IDOR/BOLA;
- SSRF;
- secret leakage;
- replay;
- privilege escalation;
- malicious webhooks;
- poisoned jobs;
- data exfiltration;
- denial of service.

## Output
Threats, mitigations, tests, telemetry and residual risk.
Critical unresolved risks block production.
