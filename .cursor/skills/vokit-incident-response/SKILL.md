# Vokit Incident Response Skill

## Use when
Use during outages, security incidents, financial mismatches, call-routing failures, recording access incidents or tenant DB failures.

## Procedure
1. Detect and classify.
2. Contain without destructive cleanup.
3. Establish blast radius, especially tenant scope.
4. Protect evidence and audit logs.
5. Mitigate with reversible actions.
6. Verify recovery.
7. Reconcile financial/call/recording state.
8. Communicate status.
9. Write RCA and corrective actions.
10. Add regression tests and runbook updates.
